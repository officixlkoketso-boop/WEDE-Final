# Limpopo Fresh Bakes Website

This website gives customers information about Limpopo Fresh Bakes, its baked products, and how to make an enquiry.

## Pages

- Home
- About Us
- Products and Services
- Gallery
- Contact

## Features

- Responsive layout for computers, tablets, and phones
- Mobile menu with a three-line button
- Products and prices table
- Cake photo slideshow with previous and next buttons
- Contact form with basic field checking
- Hover animations for links, buttons, information boxes, and photos
